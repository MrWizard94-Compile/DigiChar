# DigiChar Desktop

DigiChar is a local-first desktop financial OS for ADHD-friendly spending decisions, subscription protection, quick transaction entry, budget envelopes, trend visualization, deterministic deal intelligence, and a private Ollama financial reflection assistant.

This repository is the desktop replacement for the original AI Studio web export. The app now runs as a Tauri desktop application with a React/Vite frontend and a Rust command backend. It no longer needs an Express server, Cloud Run URL, or Gemini API key for its current feature set.

## Stack

- React 19 + TypeScript + Vite
- Tauri 2 desktop shell
- Rust native command backend
- Recharts and lucide-react for finance visualization and controls
- Local WebView storage with guarded JSON parsing plus JSON/CSV export tools

## Commands

Install dependencies:

```powershell
npm install
```

Run the browser preview:

```powershell
npm run dev
```

Run the desktop app in development:

```powershell
npm run desktop:dev
```

Run verification:

```powershell
npm run check
```

Build the frontend:

```powershell
npm run build
```

Build the Tauri desktop binary:

```powershell
npm run desktop:build
```

## Desktop Architecture

- `src/services/desktopApi.ts` is the single frontend bridge for native desktop features.
- `src-tauri/src/main.rs` provides deterministic native commands for categorization, coupon strategy, app benchmarking, deal parsing, financial advice, Ollama status, and expression evaluation.
- `src/components/TauriWindowHeader.tsx` uses real Tauri window APIs for close, minimize, maximize, and drag in desktop mode.
- Browser preview remains usable because every native command has a deterministic local fallback.

## Local Ollama

DigiChar connects to Docker-hosted Ollama only through the loopback endpoint `http://127.0.0.1:11434`; it never sends the financial prompt to a cloud AI provider. The advisor uses `qwen2.5:3b` by default, which is a practical quality/performance balance for a GTX 1660 Ti with 6 GB VRAM. Set `DIGICHAR_OLLAMA_URL` and `DIGICHAR_OLLAMA_MODEL` in the environment before launching the desktop app to use another local endpoint or pulled model.

The assistant displays a live connection state, offers a selector populated only with installed Ollama models, and remembers the selected model in local WebView storage. It reports a deterministic local-rule fallback whenever Ollama or the selected model is unavailable. Its risk level and safe-to-spend numbers remain calculated by DigiChar, not generated by the model.

## Data Storage

DigiChar stores transactions, subscriptions, benchmarks, preferences, and the selected Ollama model as JSON in the desktop WebView's localStorage. It does not currently use a database, cloud sync, or at-rest encryption. The app validates imported JSON, discards corrupted values per key, and provides JSON and CSV exports through the data tools.
